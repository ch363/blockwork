Blockwork - UI Mockups and Visual Spec

High fidelity reference for the implementing agents. The :root block at the top of this file's stylesheet is the design token source of truth and should be extracted verbatim into packages/ui/src/theme/tokens.ts. Every screen below is drawn at the iPad landscape reference size of 1194 x 834 points. Do not invent colours, spacing or type sizes anywhere else.

Hard rules

1. Minimum interactive hit target is 44 x 44 points. No exceptions in primary UI.
2. Never encode meaning in hue alone. Pair every colour signal with a shape, icon or value.
3. All numeric readouts use font-variant-numeric: tabular-nums.
4. The world view is never covered by persistent UI except the inspector, which overlays and does not resize it.
5. Every warn or critical notification is tappable and opens the Trace panel.
6. Panels slide from the right and are dismissible by swipe. Modals are avoided entirely.

3. Trace panel
